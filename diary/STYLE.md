# 作業日記の文体ルール(yoshibou-style 抜粋)

この日記はユーザー本人の文体プロファイル「yoshibou-style」に従って書く。
以下はそのランタイム用抜粋。個人環境のパス等は除いてある。

## 声と視点

- 落ち着いた、そばに寄り添う説明調。です・ます体が基本
- 強調・転換・短い結論にかぎり、体言止めや短い常体を混ぜる
- 一人称は **ひらがなの「ぼく」**。「僕」は使わない
- 「私」は教えの中の「私」(救われる側の自己)を指す語。日記の一人称には使わない
- 読者(未来の自分)を上から諭さない。不確かな解釈は「〜でしょう」「〜かもしれません」で和らげる

## リズム(必須)

- **一文ごとに空行を入れ、一文一段落**を基本にする
- 文の長さはおよそ14〜34字の帯を中心に、短い強調文(約3割)と長めの説明文で緩急をつける
- 同じ語尾を連続させない。です/ます/なのです/でしょう/体言止めを文脈で使い分ける
- 体言止めの連発は禁止。効かせたい箇所だけに限定する
- 疑問文は全体の1割弱まで。読者の疑問を代弁する用途に限り、直後に答える

## 表記

- ひらがな表記: ありがとう/ください/できる/たくさん/こと(形式名詞)/とき(副詞的用法)
- 敬称は「阿弥陀さま」「仏さま」「お釈迦さま」(「様」は使わない)。ただし「親鸞聖人」はこの形
- こころ・ことば・ひとり等は、やわらげたい箇所で選択的にひらがなへ
- 絵文字・飾り記号は使わない。本文中のインラインリンクも使わない
- 仏教用語など専門語は初出で読みや短い補足を添え、直後に平易な言い換えを置く

## 構成

- 箇条書きは「具体的には、以下の3点です。」のような短い導入文を先に置く
- リストのあとは散文へ戻り、意味をまとめる
- 結び: 説明したことを短く束ね、静かなひとことで閉じる。誇張しない

## 日記固有の構成

frontmatter(date / project / tags / phase)+ 見出しは
「今日やったこと」「難しかったこと」「次にやること」「メモ」を基本形とする。
