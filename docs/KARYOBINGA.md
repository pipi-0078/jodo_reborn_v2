# 迦陵頻伽：浮遊姿勢のギャラリー展示

2026-09-26、承認済みfloat-2を登録。ユーザーの指示により、仮想浄土本体の阿弥陀さまの右上・後方へ1体配置。

- ギャラリーID：`karyobinga`、専用展示：`karyobinga.html`。
- 形状：541,525三角形、6メッシュ。前傾約19度、下半身と尾が後ろへ流れる姿。
- 動作：浮遊・呼吸・瞬き・翼・薄布・両手と横笛。21.6秒ループ、4骨、8アニメーショントラック。
- 生成：fal.ai経由Tripo H3.1。承認済み頭部を接続し、本プロジェクトで姿勢とアニメーションを調整。

## データ保持と配信

承認済みGLBをgzipで可逆圧縮。53,411,608→22,125,237 bytes。形状・表面画像・モーフ・骨格・アニメーションは削減も再生成もしていない。容量の削減は通信量の削減であり、描画負荷やFPSの改善率ではない。

`public/assets/karyobinga/manifest.json` に原本のSHA-256を記録。専用展示が展開してGLTFLoaderへ渡し、同じ展開済みGLBをダウンロードできる。サーバーがすでに展開して返した場合もヘッダー判定で二重展開を避ける。

`src/birds/karyobinga/viewer.js` は保存されたクリップを再生するだけで、実行時のリグ再生成や変形範囲の再判定を行わない。立ち姿への接地補正や金色への材質置換も行わない。

## 表示と負荷

全身／顔／側面／背面、一時停止・再開、GLB保存。ギャラリーでは既存のiframe展示方式を使用。品目切り替え時は前のiframeを解除する。上限30fps、画素比上限1.5、非表示タブでは停止。OSのモーション低減設定を尊重。

## 検証

`npm run build` 後、`npm run preview -- --host 127.0.0.1 --port 8941` で配信。

`node tools/verify_karyobinga_gallery.cjs` で登録・埋め込み読み込み・瞬きと浮遊・ダウンロードの原本ハッシュ一致・品目切り替え・390px幅を確認。`GALLERY_BASE` と `OUTPUT_DIR` で確認先と保存先を指定可能。

## 仮想浄土への配置

`src/world/layout.ts` の `KARYOBINGA_HOME` / `KARYOBINGA_SCALE` で管理。東側から正面を見る基準で、原点は (-5.6, 11.85, -7.7)、倍率3.29、東向き。クリップ内の浮遊高さがさらに加わるため、足元も阿弥陀像の頭上に位置する。配置用の親グループをアニメーション階層の外に置き、承認済みの前傾・浮遊・表情を保持。

ギャラリーと同じ可逆圧縮GLBを読み込み、全8トラックを再生。アニメーション更新は30Hz、非表示時は本体ループで休止。共有の影へ参加。形状の簡略化は行っていないため54万三角形分の描画負荷は追加される。

西日と羅網の影で羽が黒く沈まないよう、元の色テクスチャによる弱い補光（emissiveIntensity 0.18）をこの個体に限定して追加。
