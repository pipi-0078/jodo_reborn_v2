# 共命之鳥の白蓮上配置

2026-10-02。承認済みの紅・金の二頭の鳥と、飲水・羽繕い・開翼の36秒ループを仮想浄土へ統合。

- アセット: `public/assets/gumyocho-on-lotus.glb`。承認済みGLBとバイト一致、SHA-256 `aa61ad59eaf2846da0dffb466f4843ff1ae83f5065fc99bc828d3b93503253f1`。
- 設置先: 開始地点から見て池左奥、既存の白い満開蓮のindex 8。蓮の原点 `(-16.007722530, -0.552616386, 29.657408300)`、倍率 `1.753879524`、向きは既存のまま。
- 組み合わせGLBを倍率 `0.876939762`、高さ `-0.203594360` に配置。既存蓮1株を置き換え、花弁を既存の白色・発光へ合わせる。鳥の形状・テクスチャ・骨格・クリップは変更しない。
- 白蓮の手前で重なっていた青蓮index 2のみX方向へ-2m寄せ、花とその光を一緒に移動。白蓮との実外周の間隔は約44cm、岸水際まで約86cmを確保。ほかの蓮の乱数列・位置は維持。
- `Everyday life` を連続再生。飲水、羽繕い、休息、開翼の個別クリップもGLB内に保持。
- 飲水地点の波高差を抑えるため、蓮から2.5m以内は波の振幅を2.5%にし、4mまでで通常へ戻す。池の他の部分は従来の波のまま。
- `?view=gumyocho` で最寄り外岸から見られる。通常の入場地点は変更しない。ギャラリーでも内蔵クリップを再生する。

検証コマンド: `npm run build`、ローカルプレビュー起動後 `node tools/verify_gumyocho.cjs`。保存先は `OUTPUT_DIR`、対象URLは `GUMYOCHO_BASE` で指定できる。

スキニング後の145時点で足の移動は0。花托までの足先の間隔は右0、左約5mm。飲水時の嘴先は基準水面下約1.8cm。蓮の原点差は0。ブラウザーの描画・モデル通信・アニメーションとギャラリー再生を確認する。ギャラリーの縦長390×844およびresizeでは、36秒全145時点の全頂点が画面内に収まることを数値投影で検証済み。

一体メッシュに関節を追加した動作のため、首・足首・翼の付け根の変形は近似。羽根一本ずつの物理運動を再現するものではない。
